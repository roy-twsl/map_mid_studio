## 🌐 English

### 📖 Overview
**Mind Map Studio v2.0.0** is an ultra-fast, single-file, production-ready Mind Mapping tool designed for seamless brainstorming, knowledge structuring, and book/article summarization. It requires **zero external network requests, zero CDNs, and zero third-party libraries**, operating entirely in-memory on your local machine.

---

### ✨ Key Features

- **100% Standalone & Offline:** Everything is bundled inside a single `index.html` file. No internet connection or installation required.
- **AI & Structured JSON Importer:** Paste JSON or indented Markdown outlines generated by LLMs (ChatGPT, Claude, Gemini) to instantly generate, style, and auto-balance complete mind maps.
- **Buzan's 360° Clockwise Engine:** Sequences direct branches from Top-Right (1 o'clock to 5 o'clock) through Bottom-Left up to Top-Left (7 o'clock to 11 o'clock) in an uninterrupted circular flow.
- **Dynamic Weight-Balanced Layout:** Balances cumulative subtree heights across both sides to maintain optical 50/50 symmetry.
- **Exact Geometric Midpoint Centering:** The Root Node is placed dead-center relative to the canvas and all child branches.
- **Strict Bidirectional Isolation:** Native Persian (RTL) and English (LTR) rendering with isolated context—mixed sentences with leading English words will never invert.
- **Single-Line vs Multi-Line Mode:** Choose per-node text wrapping. Single-line mode dynamically extends node width with zero line breaks.
- **Non-Overflowing High-Res Exporter:** Re-engineered Canvas/PNG and pure native PDF 1.4 binary stream compiler that matches live screen layouts without text clipping.
- **Fullscreen Image Lightbox:** Interactive edge-to-edge modal with mouse wheel zooming, drag-to-pan, and direct download.
- **Encrypted Local Persistence (.pmm):** Saves project files using a proprietary client-side cipher with all Base64 images permanently embedded.
- **Full Undo / Redo:** Multi-step history stack with `Ctrl + Z` and `Ctrl + Y`.
- **Node-Specific Context Menu:** Right-click directly on nodes for quick actions with child-deletion safety confirmations.
- **Default Clean Light Theme:** Clean minimalist Light Mode by default, switchable to Dark Mode.

### 🤖 AI Prompt Template & JSON Schema

#### 1. JSON Schema
```json
{
  "title": "Machine Learning & AI",
  "lang": "en",
  "emoji": "🧠",
  "nodes": [
    {
      "title": "Supervised Learning",
      "emoji": "🎯",
      "children": [
        { "title": "Linear Regression", "emoji": "📈" },
        { "title": "Classification Models", "emoji": "🏷️" }
      ]
    },
    {
      "title": "Unsupervised Learning",
      "emoji": "🔍",
      "children": [
        { "title": "K-Means Clustering", "emoji": "🧩" },
        { "title": "Dimensionality Reduction", "emoji": "📉" }
      ]
    }
  ]
}
```

#### 2. Prompt for ChatGPT / Claude / Gemini
```text
Please analyze the text below and convert it into a structured hierarchical Mind Map in valid JSON format.

Output Rules:
1. 'title': Main core topic.
2. 'lang': Language code ("en" for English, "fa" for Persian).
3. 'emoji': Relevant single emoji for each node.
4. 'nodes': Array of primary branch objects, with nested 'children' arrays.
5. Output ONLY the raw valid JSON code block without conversational text.

[Paste your book, article, or notes text here]
```

### 🚀 Getting Started

#### Local Usage
1. Download or clone this repository.
2. Double-click `index.html` to open it in any modern browser (Chrome, Firefox, Safari, Edge).
3. No internet connection, server, or build step is needed.

#### GitHub Pages Deployment
1. Go to your repository **Settings** -> **Pages**.
2. Under **Build and deployment**, set **Branch** to `main` and folder to `/ (root)`.
3. Click **Save** to receive your live web app URL.

## 🇮🇷 فارسی (Persian)

### 📖 معرفی
**مایند مپ استودیو (نسخه ۲.۰.۰)** یک ابزار تک‌فایلی، مدرن و کاملاً آفلاین برای طراحی و مدیریت نقشه‌های ذهنی است. این نرم‌افزار بدون نیاز به اینترنت و بدون حتی یک خط کتابخانه خارجی اجرا شده و قابلیت تولید خودکار مپ از روی متن و هوش مصنوعی را در اختیارتان قرار می‌دهد.

---

### ✨ ویژگی‌های کلیدی

- **۱۰۰٪ مستقل و آفلاین (Zero Dependency):** اجرای کامل در قالب یک فایل `index.html` واحد بدون نیاز به نصب یا اینترنت.
- **ورود خودکار ساختار هوش مصنوعی و JSON:** تبدیل آنی خلاصه کتاب‌ها یا مقالات تولیدشده توسط ChatGPT/Claude به مایند مپ همراه با آیکون‌ها و تشخیص خودکار جهت و زبان (`fa` یا `en`).
- **چیدمان استاندارد ۳۶۰ درجه ساعت‌گرد (قانون تونی بوزان):** توزیع شاخه‌ها از بالا-راست تا پایین-راست، و از پایین-چپ تا بالا-چپ در یک چرخه پیوسته.
- **توازن وزنی پویا (Dynamic Weight Balancing):** محاسبه ارتفاع زیرشاخه‌ها برای ایجاد تقارن ۵۰/۵۰ میان ستون‌های چپ و راست.
- **تراز هندسی دقیق نود مادر:** قرارگیری نود اصلی دقیقاً بر مرکز عمودی و افقی صفحه.
- **پشتیبانی ایزوله دوزبانه (فارسی و انگلیسی):** متن‌های ترکیبی فارسی همراه با عبارات انگلیسی بدون جابه‌جایی کلمات یا به‌هم‌ریختگی پرانتزها رندر می‌شوند.
- **حالت تک‌خطی و چندخطی نودها:** امکان تنظیم نحوه نمایش متن نود در یک خط ممتد یا چند خط شکسته شده.
- **موتور خروجی بدون بیرون‌زدگی متن (PNG و PDF):** رندرینگ مستقل روی بوم با رزولوشن بالا و انطباق ۱۰۰٪ با آنچه روی صفحه نمایش مشاهده می‌کنید.
- **لایت‌باکس تمام‌صفحه تصاویر:** قابلیت زوم آزادانه با اسکرول ماوس و جابه‌جایی (Pan) روی تصاویر تعبیه‌شده.
- **فرمت فایل انحصاری رمزنگاری‌شده (.pmm):** ذخیره تمام ساختار مپ و رشته‌های باینری تصاویر به‌صورت مستقل برای بازگشایی در هر سیستم دیگر.
- **سیستم بازگشت به قبل و بعد (Undo / Redo):** تاریخچه ۵۰ مرحله‌ای برای تمام تغییرات با `Ctrl + Z` و `Ctrl + Y`.
- **منوی راست‌کلیک اختصاصی روی نودها:** دسترسی سریع به ویرایش، افزودن شاخه، تغییر رنگ، آیکون، تصویر و حذف با تاییدیه امنیتی.
- **تم پیش‌فرض روشن (Light Mode):** طراحی مینیمال و تمیز در حالت روشن با قابلیت سوییچ به دارک‌مد.

### 🤖 ساختار JSON و پرامپت آماده هوش مصنوعی

#### ۱. ساختار نمونه JSON
```json
{
  "title": "هوش مصنوعی و یادگیری ماشین",
  "lang": "fa",
  "emoji": "🧠",
  "nodes": [
    {
      "title": "مفاهیم پایه و اصول",
      "emoji": "💡",
      "children": [
        { "title": "تعریف الگوریتم و منطق", "emoji": "⚙️" },
        { "title": "انواع داده‌های متنی و تصویر", "emoji": "📊" }
      ]
    },
    {
      "title": "روش‌های یادگیری",
      "emoji": "🚀",
      "children": [
        { "title": "یادگیری بانظارت (Supervised)", "emoji": "🎯" },
        { "title": "یادگیری بدون نظارت (Unsupervised)", "emoji": "🔍" }
      ]
    }
  ]
}
```

#### ۲. پرامپت آماده برای ChatGPT / Claude / Gemini
```text
لطفاً متن زیر را با دقت تحلیل کرده و یک مایند مپ سلسله‌مراتبی از آن در قالب یک ساختار معتبر JSON تولید کن.

قوانین خروجی:
۱. فیلد title: عنوان اصلی متن/کتاب.
۲. فیلد lang: زبان متن ("fa" برای فارسی یا "en" برای انگلیسی).
۳. فیلد emoji: یک ایموجی مرتبط برای هر نود.
۴. فیلد nodes: آرایه‌ای از شاخه‌های اصلی، که هر کدام می‌توانند دارای زیرشاخه در فیلد children باشند.
۵. خروجی صرفاً یک بلاک کد JSON معتبر باشد و هیچ توضیح اضافه قبل یا بعد از آن ننویس.

[متن کتاب، مقاله یا جزوه شما در اینجا]
```

### 🚀 نحوه اجرا و راه‌اندازی

#### اجرای محلی (آفلاین)
۱. فایل‌های پروژه را دانلود کنید.  
۲. روی فایل `index.html` دابل‌کلیک کنید تا در مرورگر اجرا شود. نیازی به اینترنت یا هیچ ابزار اضافی نیست.

۱. در مخزن گیت‌هاب خود به بخش **Settings** -> **Pages** بروید.  
۲. در قسمت **Branch** شاخه `main` و پوشه `/ (root)` را انتخاب کرده و **Save** کنید.  
۳. پس از ۱ دقیقه لینک اجرای آنلاین برنامه آماده است.
